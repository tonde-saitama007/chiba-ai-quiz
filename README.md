# 千葉愛クイズ

千葉の名所・食・文化・歴史に挑戦する、非公式の無料クイズです。

## 仕様
- 全30問から重複なしでランダム10問、4択、各問15秒
- 正解8点＋早押しボーナス（5秒以内2点、10秒以内1点）、100点満点
- 5段階称号：千葉ルーキー／千葉探検家／千葉通／千葉愛の達人／房総マスター
- 結果の操作は画像保存・公開URLコピー・再挑戦の3つ
- 外部ライブラリ・APIキー不要。PNGはブラウザ内で生成
- 海の青と菜の花の黄色を使い、既存の県愛クイズと操作性を統一

公開先：https://tonde-saitama007.github.io/chiba-ai-quiz/

## 出典
SOURCES.mdに問題ごとの確認資料を掲載しています。問題文・解説・称号は本クイズ向けに作成しています。公式キャラクター画像や他サイトの写真は使用していません。

## 検証
verification/check-chiba.cjsはNode.js標準機能で実行する採点・抽選等の検査です。DOM代替環境であり、実ブラウザ検証とは区別してください。
